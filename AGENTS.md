# AI Agent Instructions & Guidelines

This project enforces **anti-slop** (`miqdadbadjuber/anti-slop`) rules to prevent generic AI clichés, artificial step badges, filler copy, and low-taste patterns.

## Anti-Slop Core Directives

1. **No Artificial Step Indicators / Fluff Badges**:
   - Do not invent floating pill badges like "Langkah 1 dari 3" or artificial step numbers when unnecessary.
   - Keep forms, actions, and layouts honest, purposeful, and grounded in real project context.

2. **No Generic Visual Slop**:
   - Avoid generic AI clichés: default purple/cyan gradients, random floating emoji pill tags, excessive sparkle icons (✨), and empty buzzword cards.
   - Maintain the established brand palette: FEB UB Navy (`#092b4c`), Lustrum Gold (`#d3a128`), and clean institutional styling.

3. **No Corporate/Marketing Slop in Copy**:
   - Write clear, concise, direct Indonesian instructions.
   - Avoid breathless promotional hype, hollow superlatives, and artificial excitement.

4. **Code Quality**:
   - Do not write defensive dead code, empty error swallowers, or redundant comment noise.
   - Write clean, maintainable, production-ready code aligned with existing architecture.

Full rules and skills are located in `.agents/rules/` and `.agents/skills/`.
